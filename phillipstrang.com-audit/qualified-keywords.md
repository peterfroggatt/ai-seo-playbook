# Qualified Keyword Pool — from Amazon Ads converting search terms (UK + AU)

Extracted from the Sponsored Products search-term reports: terms that earned clicks + sales/KENP,
ASINs stripped, then **human-curated** (the raw genre-word filter wrongly included competitor series).

**Data caveat:** Amazon's search-term report spreads a handful of orders across many contributing
terms, so per-term "sales" figures are directional demand signal, NOT precise revenue. Use this list
for *what to include*, not for *how much each earns*.

---

## C. How Cowork uses this file

1. Treat **Section A** as the qualified `[ad]` keyword pool referenced in the metadata brief — assign
   phrases to each book by series, fill the 7 fields, tag `[ad]`.
2. Supplement per book with 2–3 `[derived]` terms (specific setting/character) only if they pass the
   4 gates — do not pad with competitor series names.
3. Hand **Section B** to the ads workstream, not metadata.
4. Flag the broad-match cozy-mystery mismatch (many converting terms were cozy series) → add cozy terms
   as **negatives** in the ad campaigns; they're the wrong audience for dark procedurals.
